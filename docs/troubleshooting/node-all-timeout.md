# 节点全部超时、全红与 TIMEOUT 无法连接故障终极解决指南 (2026 最新)

<QuickAnswer>
<strong>核心结论：</strong>在 Clash 或 v2rayN 中执行测速时<strong>所有节点全部变红、显示 Timeout 或 -1ms</strong>，绝非系统中毒或软件损坏。<strong>95% 的原因集中在以下 4 点</strong>：<strong>① 本地系统时间与标准北京时间不同步</strong>（偏差超 1 分钟会导致 TLS 握手瞬间被拒）；<strong>② 套餐流量耗尽或订阅已到期</strong>；<strong>③ 本地安全软件或防火墙拦截了客户端核心组件</strong>；<strong>④ 节点服务器 IP 被防火墙集中阻断或服务商临时维护</strong>。请先右键点击订阅进行【更新】，并手动同步电脑系统时间。
</QuickAnswer>

## 一、节点全部超时的六大核心技术诱因

当客户端对节点列表发送握手测试请求时，如果未在指定时间（通常为 3000ms ~ 5000ms）内收到服务端的回包，就会标记为 `Timeout / 超时`。常见诱因如下：

```text
                               ┌──> 1. 本地系统时钟偏差 > 60秒 (TLS握手直接失败)
                               ├──> 2. 账号流量用尽 / 订阅到期
【客户端发起测速握手】 ──(拦截)──┼──> 3. 杀毒软件/Windows防火墙拦截 Xray/Mihomo 核心
                               ├──> 4. 代理本地端口冲突 (如 7890 端口被其他软件占用)
                               ├──> 5. 免费节点服务器已全部下线 / 域名被污染
                               └──> 6. 本地网络营运商 (如移动) 阻断了特定协议端口
```

## 二、六步标准排错与修复流程

```mermaid
graph TD
    Step1[第 1 步: 同步电脑/手机系统时间] --> Step2[第 2 步: 检查机场后台账号状态与流量余额]
    Step2 --> Step3[第 3 步: 右键更新订阅拉取最新节点]
    Step3 --> Step4[第 4 步: 检查本地代理端口占用(重启核心)]
    Step4 --> Step5[第 5 步: 临时关闭第三方杀毒软件测试]
    Step5 --> Step6[第 6 步: 切换网络环境(手机热点测试)]
```

### 第 1 步：精准同步系统时间（最高频杀手）
这是导致节点“明明可用却全部超时”的最常见原因：
- **Windows 电脑**：右下角右键点击时间 →【调整日期和时间】→ 确保开启“自动设置时间”，点击 **“立即同步”**。
- **macOS 苹果电脑**：【系统设置】→【通用】→【日期与时间】→ 开启“自动设置日期和时间”。
- **手机设备**：【设置】→【通用/系统】→【日期和时间】→ 开启“自动设置”。

### 第 2 步：登录机场后台核验账号与流量状态
打开浏览器登录您的服务商后台：
1. 检查套餐**是否已过期**。
2. 检查当月**流量配额是否已用尽**。
3. 很多时候节点超时仅仅是因为当月流量耗尽，系统自动关闭了连接权限。

### 第 3 步：手动更新订阅链接
由于网络波动或服务器维护，服务商可能更换了节点后端 IP 或协议端口：
- **Clash Verge Rev**：进入【订阅】页面，在配置卡片上点击鼠标右键，选择 **“更新 (Update)”**。
- **v2rayN**：点击顶部【订阅分组】→ **“更新全部订阅 (不通过代理)”**。
- **小火箭**：在首页下拉屏幕触发全局刷新。

### 第 4 步：排查本地端口占用与核心冲突
如果电脑上同时运行了多个代理工具（如同时打开了 Clash 和 v2rayN），两者会争抢 `7890` 或 `10808` 端口导致核心崩溃：
1. 打开任务管理器，结束所有 `clash-meta.exe`、`xray.exe` 或 `sing-box.exe` 残留后台进程。
2. 仅保留一个客户端运行，在设置中点击 **“重启内核”**。

### 第 5 步：防火墙与安全软件放行
某些安全管家（如 360、火绒或迈克菲）会将代理内核的频繁对外连接误判为风险行为：
1. 临时退出第三方杀毒软件。
2. 在 Windows Defender 防火墙中，确认勾选并允许了 Clash / v2rayN 程序的公用与专用网络访问。

### 第 6 步：切换手机热点测试（排除本地宽带阻断）
手机开启 4G/5G 个人热点，电脑连接手机热点后再次执行测速：
- 若连接热点后节点瞬间全部恢复绿色，说明您原本的宽带光猫开启了严格的防火墙阻断或运营商 QoS 限制；
- 此时建议在客户端中改用基于 UDP 协议的 **Hysteria 2** 节点，或联系宽带运营商将光猫改为桥接模式。
