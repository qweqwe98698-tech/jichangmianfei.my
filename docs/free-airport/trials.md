### 1. 0 元无门槛免费试用（Free Trial）
- 用户使用常规邮箱注册账号后，系统自动在用户中心发放测试订阅。
- 核心价值：零成本验证客户端环境是否正常配置（如系统代理、TUN 虚拟网卡）。相关客户端配置可参考 [Clash 免费节点配置](/free-node/clash) 与 [v2rayN 节点测速配置](/free-node/v2rayn)。

## 二、试用期内必须重点测试的 4 项硬核指标

拿到试用订阅链接后，不要仅仅满足于“能打开 Google”。必须在试用期内完成以下 4 项硬性核验：

### 1. 晚高峰速率测试 (Peak Hour Stress Test)
必须在晚上 20:30 ~ 22:30 的全国骨干网拥堵高峰期测试。打开 YouTube 搜索 `4K HDR 60fps` 视频，右键点击“详细统计信息 (Stats for nerds)”：
- **Connection Speed（连接速度）**：应稳定维持在 **50,000 Kbps (50 Mbps)** 以上。
- **Buffer Health（缓冲健康度）**：应持续在 **20 秒以上**，进度条随意拖拽无明显白圈转圈卡顿。

### 2. AI 平台纯净度测试 (AI Clean IP Test)
打开浏览器隐私无痕窗口，直接访问 `chatgpt.com` 或 `claude.ai`：
- 若能直接进入登录界面并正常生成回答，且没有触发 Cloudflare 循环人机验证或 `Access Denied 1020`，说明该试用节点的出口 IP 信誉优秀。
- 更多节点地区选择细节请参考 [国外常用节点地区选型指南](/free-node/regions)。

### 3. 多协议与客户端导入兼容性
测试试用订阅在您的主要设备上能否一键顺利同步：
- Windows 电脑端：[Clash Verge Rev 电脑教程](/tutorial/clash-verge-rev) 或 [v2rayN 实战](/tutorial/v2rayn-windows)
- iOS 苹果端：[Shadowrocket (小火箭) 教程](/tutorial/shadowrocket-ios)
- Android 手机端：Clash Meta for Android (CMFA)

### 4. 流量扣除倍率与重置规则核实
在测试下载或播放一段已知大小（如 1GB）的媒体文件前后，刷新机场用户中心后台，检查实际扣除流量是否严格对应 1.0x 标称倍率，确认不存在暗中以 2.0x 或 3.0x 偷跑流量的恶劣行为。
