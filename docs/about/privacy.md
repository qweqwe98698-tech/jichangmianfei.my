# 隐私政策与数据安全说明

本隐私政策详细说明了 **机场免费 (jichangmianfei.my)** 如何收集、使用和保护您在访问本站时的个人信息与数据安全。

## 一、我们收集哪些信息？
1. **纯静态浏览无账号系统**：本网站为纯静态静态知识库站点，网站本身不设立用户注册系统，不收集您的真实姓名、手机号、身份证号或银行卡等任何敏感个人信息。
2. **基础服务器访问日志**：与绝大多数互联网网站一样，当您访问本站时，托管服务器可能会自动记录极基础的非个人识别性访问日志（包含匿名化的 IP 地址、浏览器类型、操作系统、访问时间及请求的网页 URL），此类日志仅用于保障服务器基础安全、抵御恶意 DDoS 攻击与优化网站加载速度。
3. **本地浏览设置 (LocalStorage)**：本站使用浏览器的本地存储（LocalStorage）仅用于记录您主动选择的“深色/浅色主题外观”以及“折叠菜单状态”，不包含任何用户追踪信息。

## 二、第三方服务与外部链接
1. **外部服务商官网**：当您点击本站中的外部推荐链接（如光速云官网）并离开本站后，您在第三方平台上进行的注册、支付与使用行为将受该第三方平台自身的隐私政策与服务条款约束。我们强烈建议您在向任何第三方提交个人信息前查阅其隐私条款。
2. **CDN 与静态资源加速**：为了保障全球访问速度，本站的静态资源（CSS、JS、字体与开源图标）可能通过合规的公共 CDN 进行加速分发。

## 三、Cookie 的使用政策
本站默认不植入任何用于跨站行为广告追踪的第三方 Cookie。本地仅保留保障 VitePress 基础功能（如全文搜索索引缓存、页面渲染缓存）所必需的无害临时数据。您随时可以通过浏览器的“清除浏览数据”功能将其完全清除。
